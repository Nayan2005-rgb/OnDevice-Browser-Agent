Scenarios

  1. A — Normal: Run multi-step plan → Pause → Resume → Complete (dashboard / extension).
  2. B — Restart: Complete step 1 → restart backend with hydrate → reconnect extension → recover with fresh perception.
  3. C — Page changed during pause: Pause → switch to Layout B → Resume → structural change → replan preview.
  4. D — Approve replan: Create session with operator_replan_approval → approve preview → plan version increments.
  5. E — Reject replan: Reject preview → session paused with reason replan_rejected_by_operator.
  6. F — Intervention: Show login → agent pauses → user signs in manually → resume with fresh perception.
