Scenario A — Search + open first result Happy path

Task: Search for AI courses and open the first result

  1. Type into #search-box
  2. Click #search-button
  3. Wait until results are visible
  4. Fresh perception → click first result
  5. Plan completes

Scenario B — Delete requires confirmation Confirm

Task: Search for demo item and delete the first result

  1. Safe search steps execute
  2. Delete step pauses plan (waiting_for_confirmation)
  3. Dashboard confirm → tab claims once → delete executes → verify → complete

Scenario C — Cancel during execution Cancel

Start Scenario A, then use popup Cancel Plan.

Completed steps remain recorded; future steps are never executed.

Scenario D — Target disappears Recovery
